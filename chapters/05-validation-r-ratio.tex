\chapter{Validation}\label{ch:validation}

The antenna function computed in the previous chapter and all others in SMQCD (and other models) 
find their primary application in 
infrared subtraction schemes for higher-order cross-section calculations. Real-emission 
contributions to fixed-order cross sections are individually divergent in the soft and collinear 
limits, and standard numerical integration fails at these phase-space boundaries. The 
subtraction approach resolves this by introducing a local counterterm with precisely the 
same singular behaviour as the real-emission matrix element at every phase-space point, so 
that their difference is finite and numerically integrable. For this cancellation to hold 
locally, the subtraction term must reproduce the universal QCD singular structure in each 
unresolved limit: the soft eikonal factor,
\begin{equation}\label{eq:eikonal}
    \mathcal S_{12}^{(3)} = 2\frac{s_{12}}{s_{13}s_{23}}
\end{equation}
in the soft $k_3\to 0$ limit, and the Altarelli-Parisi splitting function,
\begin{equation}\label{eq:APfunction}
    P_{qg}(z) = \frac{1+z^2}{1-z}
\end{equation}
in the collinear $s_{13}\to0$ limit. In the antenna subtraction formalism, the antenna functions
represent these local counterterms. In Section~\ref{sec:validationLocal} we verify that the 
unintegrated $A_3^0$ antenna generated by \textcolor{red}{AntCalc} reproduces both structures
exactly.

Global consistency of the full antenna set is then tested via the computation of the massless 
hadronic R-ratio up to NNLO in Section~\ref{sec:validationGlobal}. At each order the result is
assembled from the integrated antenna functions computed using \textcolor{red}{AntCalc} and
infrared poles must cancel exactly in the sum before a finite physical coefficient can be
achieved.

\section{Soft and Collinear Limits of $A_3^0$}\label{sec:validationLocal}

Applying those limits to our $A_3^0$ unintegrated antenna enables us to verify those results.

First, the eikonal factor at the soft limit is computed as follows,
\begin{equation}
    \mathcal S_{12}^{(3)} = \lim_{k_3\to 0} A_3^0(1_q, 3_g, 2_{\bar q}).
\end{equation}

Using \textcolor{red}{AntCalc}, computing this eikonal factor goes as,
\begin{mdframed}[backgroundcolor=gray!10, linewidth=0pt]
    \texttt{In[2]:= intA30 = BuildAntenna[A,3,0];\\
                    \\
                    softSubs = {s13 -> lambda * s13, s23 -> lambda * s23};\\
                    A30Soft = A30 /. softSubs;\\
                    \\
                    A30SoftSeries = Series[A30Soft, {lambda, 0, 0}];\\
                    \\
                    eikonalFactor = SeriesCoefficient[A30SoftSeries, -2] /. q2 -> s12\\ 
                    // Simplify;}\\
    \hfill
    \texttt{Out[2]:=}
        \begin{equation*}
            \frac{2s_{12}}{s_{13}s_{23}}
        \end{equation*}
\end{mdframed}

Computing the Altarelli-Parisi splitting function is very similar do computing the eikonal factor,
but using the collinear limit instead of the soft limit, as follows,
\begin{equation}
    P_{qg} (z) = \lim_{k_1||k_3}A_3^0(1_q, 3_g, 2_{\bar q})
\end{equation}
and using \textcolor{red}{AntCalc},
\begin{mdframed}[backgroundcolor=gray!10, linewidth=0pt]
    \texttt{In[3]:= intA30 = BuildAntenna[A,3,0];\\
                    \\
                    collinearSubs = {s13 -> lambda, s12 -> z q2, s23 -> (1 - z) q2, \\Epsilon
                     -> 0};\\
                    A30Colliner = A30 /. collinearSubs;\\
                    \\
                    A30CollinearSeries = Series[A30Colliner, {lambda, 0, 0}];\\
                    \\
                    apSplittingFunc = 1 / q2 SeriesCoefficient[A30CollinearSeries, -1]\\ 
                    // Simplify;}\\
    \hfill
    \texttt{Out[3]:=}
        \begin{equation*}
            \frac{1+z^2}{1-z}
        \end{equation*}
\end{mdframed}
which both equal their respective known results in Eqs.~\ref{eq:eikonal} and \ref{eq:APfunction}.

\section{The Massless SMQCD R-Ratio}\label{sec:validationGlobal}

The hadronic R-ratio is usually defined as the ratio of total cross-section for $e^+e^-$
annihilation into hadrons to the point-like cross-section for $e^+e^-\to\mu^+\mu^-$, that is,
it is the ratio of the cross-sections of the topologies where the electron-positron pair
annihilates into hadrons and into a muon-antimuon pair. It is mathematically described 
as follows,
\begin{equation}
    \begin{split}
        R_\text{hadr} &= \frac{\sigma(e^+e^-\to\text{hadrons})}{\sigma(e^+e^-\to\mu^+\mu^-)}\\
          &= \frac{3q^2}{4\pi\alpha_s^2}\,\sigma(e^+e^-\to\text{hadrons}).
    \end{split}
\end{equation}

Looking closely, the $\sigma(e^+e^-\to\text{hadrons})$ term is what QCD predicts for the 
$\gamma^*\to\text{hadrons}$, computed via the optical theorem \textcolor{red}{[ref to the optical theorem]}.
What makes the R-ratio a clean QCD observable, and a good benchmark for \textcolor{red}{AntCalc}
is that the ratio features terms for higher perturbation orders as a perturbative series in $\alpha_s$,
\begin{equation}
    R_\text{hadr} = \left(c_\text{LO}+\frac{\alpha_s}{\pi}c_\text{NLO}+\left(\frac{\alpha_s}{\pi}\right)^2c_\text{NNLO}+\mathcal O\left(\alpha_s^3\right)\right)
\end{equation}
here the perturbative coefficients, $c_\text{LO}$, $c_\text{NLO}$ and $c_\text{NNLO}$, respectively receive 
contributions from the multiparticle final states at the relative orders, and respective antennae, 
as described in Chapter~\ref{ch:physicsbackground}. For example, 
$A_3^0$ as described in Chapter~\ref{ch:workedexample} contributes to $c_\text{NLO}$.
Moreover, the leading order term $R^{(0)}$ simply counts the number of quark colours and flavours
weighted by their electric charges,
\begin{equation}
    R^{(0)} = N_c\sum_q e_q^2
\end{equation}
from $R_\text{hadr}=R^{(0)}\big(1+\mathcal O(\alpha_s)\big)=R^{(0)}R(\alpha_s)$. 

To compute the R-ratio, we will start by computing the three coefficients using the integrated
antennae. Those integrated antennae will be assembled into $\mathcal T$-objects, as described in 
Chapter~\ref{ch:physicsbackground}, and those will finally be used to assemble the $R$ 
perturbative series.

In this chapter, as the title suggests we will be focusing on the SMQCD R-ratio, not SUSY or 
HiggsEFT. That means that we will only be using A-, B- and C-type antennae. 

\subsection{Computing the Integrated Antennae and $\mathcal T$-objects}

As shown in Chapter~\ref{ch:workedexample}, building and integrating antennae is made very easy
using \textcolor{red}{AntCalc}. Since our goal is to use the all integrated antennae in SMQCD
we can make use of the\\ \texttt{BuildAndIntegrateAllAntennae[model]} function. The integrated
antennae will be generated as follows,

\begin{mdframed}[backgroundcolor=gray!10, linewidth=0pt]
    \texttt{In[2]:= \{intA20,intA30,intA21,\{intA40, intTildeA40, intHatA40\}, \\
    intB40, intC40, 
    \{intA31, intTildeA31, intHatA31\}, \{intA22, \\intTildeA22, intHatA22, intBreveA22\}\} = 
    \\BuildAndIntegrateAllAntennae[SMQCD, maxOrder->NNLO, \\ExpansionOrder -> 2];}
\end{mdframed}
which generates all integrated antennae up to NNLO and up to the $\epsilon^2$ term, in the SMQCD 
model.

The $\mathcal T$-objects, as described in Subsection~\ref{subsec:antFamilies}, 
are then assembled as,
\begin{equation}
    \begin{split}
        &\mathcal T_{q\bar q}^2 = 4N(1-\epsilon)\\
        &\mathcal T_{q\bar q}^4 = \left(N-\frac1N\right)\mathcal T_{q\bar q}^2\mathcal A_2^1\\
        &\mathcal T_{q\bar qg}^4 = \left(N-\frac1N\right)\mathcal T_{q\bar q}^2\mathcal A_3^0\\
        &\mathcal T_{q\bar q}^6 = \left(N-\frac1N\right)\mathcal T_{q\bar q}^2\Bigg[N\mathcal A_2^2 + \frac1N\tilde{\mathcal A_2^2} + N_f\hat{\mathcal A_2^2}+\left(N-\frac1N\right)\breve{\mathcal A_2^2}\Bigg]\\
        &\mathcal T_{q\bar qg}^6 = \left(N-\frac1N\right)\mathcal T_{q\bar q}^2\Bigg[N\left(\mathcal A_3^1+\mathcal A_2^1\mathcal A_3^0\right)-\frac1N\left(\tilde{\mathcal A_3^1}+\mathcal A_2^1\mathcal A_3^0\right)+N_f\hat{\mathcal A_3^1}\Bigg]\\
        &\mathcal T_{q\bar qq^\prime\bar q^\prime}^6 = \left(N-\frac1N\right)\mathcal T_{q\bar q}^2(N_f-1)\mathcal B_4^0\\
        &\mathcal T_{q\bar qq\bar q}^6 = \frac1{N_f-1}\mathcal T_{q\bar qq\bar q^\prime q^\prime}^6 - \mathcal T_{q\bar q}^2\left(N-\frac1N\right)\frac1N\mathcal C_4^0\\
        &\mathcal T_{q\bar qgg}^6 = \left(N-\frac1N\right)\mathcal T_{q\bar q}^2\left(N\mathcal A_4^0 - \frac1N\tilde{\mathcal A_4^0}\right)
    \end{split}
\end{equation}
and in terms of the \textit{Wolfram} language,

\begin{mdframed}[backgroundcolor=gray!10, linewidth=0pt]
    \texttt{In[3]:=\\ 
                    Tqq2 = 4 n * (1 - eps);\\
                    Tqq4 = (n - 1 / n) Tqq2 intA21;\\
                    Tqqg4 = (n - 1 / n) Tqq2 intA30;\\
                    Tqq6 = (n - 1 / n) Tqq2 * (n * intA22 + 1 / n * intTildeA22 + nf * \\
                    intHatA22) + Tqq2 * (n - 1 / n) \^{} 2 * intBreveA22;\\
                    Tqqg6 = (n - 1 / n) Tqq2 (n * (intA31 + intA21 intA30) - 1 / n * \\
                    (intTildeA31 + intA21 intA30) + nf intHatA31);\\
                    Tqqqqprime6 = (n - 1 / n) Tqq2 * (nf- 1) * intB40;\\
                    Tqqqq6 = 1 / (nf - 1) * Tqqqqprime6 - Tqq2 (n - 1 / n) * 1 / n *\\ 
                    intC40;\\
                    Tqqgg6 = (n - 1 / n) Tqq2 * (n intA40 - 1 / n *\\ 
                    intTildeA40);}
\end{mdframed}

\subsection{Assembling the R-ratio}

With the $\mathcal T$-objects in hand, we now have everything we need to generate the R-ratio for
SMQCD. To finally do that, we use the following formula,
\begin{equation}
    \begin{split}
        R  = \frac{R_\text{hadr}}{R^{(0)}}&= R_\text{LO} + R_\text{NLO} + R_\text{NNLO}\\
          &= r_\text{LO} + \frac{\alpha_s}{2\pi} r_\text{NLO} + \left(\frac{\alpha_s}{2\pi}\right)^2 r_\text{NNLO}\\
          &= 1 + \frac{\alpha_s}{2\pi} \frac{\mathcal T_{q\bar q}^4 + \mathcal T_{q\bar qg}^4}{\mathcal T_{q\bar q}^2}+\left(\frac{\alpha_s}{2\pi}\right)^2\frac{\mathcal T_{q\bar q}^6 + \mathcal T_{q\bar qg}^6+\mathcal T_{q\bar qq\bar q}^6+\mathcal T_{q\bar q q^\prime\bar q^\prime}^6+\mathcal T_{q\bar qgg}^6}{\mathcal T_{q\bar q}^2}+\mathcal O\left(\alpha_s^3\right).
    \end{split}
\end{equation}

Substituting the integrated antennae in we are able to show that the perturbative orders equal,
\begin{equation}
    \begin{split}
        &r_\text{LO} = 1\\
        &r_\text{NLO} = \left(N-\frac1N\right)\left(\mathcal A_2^1 +\mathcal A_3^0\right)\\
        &r_\text{NNLO} = \left(N-\frac1N\right)\Bigg[N\left(\mathcal A_2^1\mathcal A_3^0+\mathcal A_3^1+\mathcal A_4^0+\mathcal A_2^2\right)-\frac1N\left(\mathcal A_2^1\mathcal A_3^0 + \tilde{\mathcal A_3^1}+\tilde{\mathcal A_4^0}+\mathcal C_4^0-\tilde{\mathcal A_2^2}\right)\\
        &\hspace{4.8cm} +N_f\left(\hat{\mathcal A_3^1}+\hat{\mathcal A_2^2}\right)+\left(N-\frac1N\right)\breve{\mathcal A_2^2}\Bigg]
    \end{split}
\end{equation}
these coefficients are then used to finally assemble the R-ratio, where the poles cancel to make a 
finite result, as follows
\begin{equation}
    R = 1 + \frac{\alpha_s}{2\pi}\left(\frac{N^2-1}{2N}\right)\frac{3}{2} + \left(\frac{\alpha_s}{2\pi}\right)^2\left(\frac{N^2-1}{2N}\right)\Bigg[N\left(\frac{243}{16}-11\zeta_3\right)+\frac{3}{16N}+N_f\left(-\frac{11}4+2\zeta_3\right)\Bigg]
\end{equation}
and in \textit{Wolfram},

\begin{mdframed}[backgroundcolor=gray!10, linewidth=0pt]
    \texttt{In[4]:= \\
            cLO = 1;\\
            rLO = 1;\\
            \\
            cNLO = alphaS / 2 Pi;\\
            rNLO = (Tqq4 + Tqqg4) / Tqq2;\\
            \\
            cNNLO = (cNLO) \^{} 2;\\
            rNNLO = (Tqq6 + Tqqg6 + Tqqqq6 + Tqqqqprime6 + Tqqgg6) / Tqq2;\\
            \\
            R = cLO rLO + cNLO rNLO + cNNLO rNNLO//Collect[\#,alphaS / 2 Pi]\&\\
            \\}
    \texttt{Out[4]:=}
        \begin{equation*}
            1 + \frac{\alpha_s}{2\pi}\left(\frac{N^2-1}{2N}\right)\frac{3}{2} + \left(\frac{\alpha_s}{2\pi}\right)^2\left(\frac{N^2-1}{2N}\right)\Bigg[N\left(\frac{243}{16}-11\zeta_3\right)+\frac{3}{16N}+N_f\left(-\frac{11}4+2\zeta_3\right)\Bigg]
        \end{equation*}    
\end{mdframed}

\subsubsection{Using a Shortcut}

As shown before in this text, \textcolor{red}{AntCalc} often includes quality of life features
that make the work we are taking many steps doing into a single all-inclusive function. The R-ratio
calculation is no different. 

First, \textcolor{red}{AntCalc} offers the ability to compute the $\mathcal T$-objects 
directly using the \texttt{TObject[order, finalParticles]}. That is applied as follows,

\begin{mdframed}[backgroundcolor=gray!10, linewidth=0pt]
    \texttt{In[5]:=\\ 
                    Tqq2 = TObject[2, {q, qbar}, ExpansionOrder -> 2];\\
                    Tqq4 = TObject[4, {q, qbar}, ExpansionOrder -> 2];\\
                    Tqqg4 = TObject[4, {q, qbar, g}, ExpansionOrder -> 2];\\
                    Tqq6 = TObject[6, {q, qbar}, ExpansionOrder -> 2];\\
                    Tqqg6 = TObject[6, {q, qbar, g}, ExpansionOrder -> 2];\\
                    Tqqqqprime6 = TObject[6, {q, qbar, qprime, qbarprime}, \\ExpansionOrder -> 2];\\
                    Tqqqq6 = TObject[6, {q, qbar, q, qbar}, ExpansionOrder -> 2];\\
                    Tqqgg6 = TObject[6, {q, qbar, g, g}, ExpansionOrder -> 2];}
\end{mdframed}
noting here that the default \texttt{ExpansionOrder} flag is $0$. 

Moreover, the function \texttt{BuildRRatio[model]} does exactly what we went
through in the present chapter and yields the same result. Its use goes as follows,

\begin{mdframed}[backgroundcolor=gray!10, linewidth=0pt]
    \texttt{In[6]:= BuildRRatio[SMQCD]\\}
    \\
    \texttt{Out[6]:=}
        \begin{equation*}
            1 + \frac{3\left(N^2-1\right)\alpha_s^2}{8N\pi}+\frac{\left(N^2-1\right)\alpha_s^2}{8N\pi}\left[\frac{3}{16N}+N\left(\frac{243}{16}-11\zeta_3\right)+N_f\left(-\frac{11}4+2\zeta_3\right)\right]
        \end{equation*}    
\end{mdframed}
